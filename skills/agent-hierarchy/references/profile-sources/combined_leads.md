# Executive PL+EL

The initial executive occupant holds project-wide PL responsibility and EL's
execution coordination across the project's active areas. UL is a separate,
conversation-first contact. This combination uses the new executive meaning of PL;
do not import historical instructions that made PL the user liaison.

Create a separate executive PL only when multiple EL occupants are needed and
authorized. The existing occupant retains EL and its continuing responsibilities;
a new occupant takes executive PL. Any additional EL receives an explicit share
of initiative/area ownership under the approved expansion. There remains one
logical executive PL. No automatic area-count trigger or new integration branch
is implied. Multi-EL operation is a later expansion, not required to run this pilot.
